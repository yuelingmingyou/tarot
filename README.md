# 塔罗密卷 · 使用说明

一本可以亲手编纂的塔罗笔记：78 张大小阿尔卡那，每张牌都有元素、行星、关键词、正逆位牌义（综合 / 感情 / 事业 / 学业）和关联神话，还能上传你自己的牌组卡面、写下私人笔记。

打开网页即可使用，无需安装任何东西，手机、电脑浏览器都可以。

---

## 浏览牌义

- 点左侧边栏的牌名（或用顶部搜索框「以名寻牌」），即可查看这张牌的完整资料。
- 牌义区右上角的「正位 / 逆位」按钮切换两种解读。

## 切换与上传卡面

- 卡面左右两侧的 **◂ ▸ 箭头**（手机上直接在卡面上左右滑动，键盘 ←/→ 也可以）为同一张牌切换不同卡面。
- 卡面下方的金色标注会显示当前卡面属于哪套牌组；同一牌组有多张时显示序号（如「韦特 · 2/3」）。
- 点「上传卡面」把图片存进当前牌组；已传过会变成「加传卡面」。每张牌最多 10 张卡面，当前这张不想要了就点「移除卡面」。

## 管理牌组

- 点卡面下方的「牌组」按钮：可以缔结新牌组（比如「猫咪塔罗」）、重命名或删除。新牌组会自动加入卡面轮播。

## 编纂牌义与笔记

- 点右上角「编纂此牌」，可以修改这张牌的元素、行星、关键词、正逆位牌义和神话故事；「恢复初始」可随时回到内置内容。
- 每张牌底部都有「我的笔记」，记录你的抽牌心得，点「封存笔记」保存。编过的牌在边栏会带一颗小金星。

## 数据迁移（顶栏「迁移」）

- **导出密卷**：把牌组、卡面、编纂和笔记打包成一个 JSON 文件下载。
- **导入密卷**：在另一台设备或浏览器上选择这个文件即可恢复全部内容。

---

## 需要知道的两件事

1. **数据保存在你自己的浏览器里**（不上传服务器）。清除浏览器数据会丢失内容，上传较多卡面后建议定期「导出密卷」备份。
2. 换电脑、换浏览器时，用「导出 → 导入」即可搬家。
